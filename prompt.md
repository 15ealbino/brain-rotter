## Project idea

This is a project that builds a computer program that runs locally on a machine that does the following.

- Records a audio specifically from a group conference call meeting for work. Then the user can play a recording of the meeting and have the audio play with a transcript of the audio on one side of the screen then on the other side of the screen a couple of panels that has "brain rot". Brain Rot are videos that keep stimulating the brain. examples that I want implemented is the following: subway surfers videos, tiktok, flappy bird.

## installation
Users will follow a README to download and run the application. The readme goes over how to install the program and get the program setup. This program needs to be installable on linux, and windows
